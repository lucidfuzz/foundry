# Foundry source

The built site is `../index.html` (the repo root), which GitHub Pages serves. Theme artwork is served separately from `../assets/`.

| Path | What it holds |
| --- | --- |
| foundry-data.js | The eleven themes, five colorways each, headlines, copy, quote packs |
| render.js | Every lock screen, home screen and icon, drawn on a canvas |
| app.js | The site: steps, preview, inspector, customize controls, export, install guide |
| page.html | Page markup and styles |
| paint/*.js | Each theme's widget and idle-game art (joined into tpl.js by the build) |
| tpl.js | The Scriptable widget-script template |
| halcyon/ | Halcyon Biofab's renderer: paint.js and fidelity.js (shared by preview and iPhone), browser.js, runtime.js |
| art.js, art-manifest.js | Loads theme artwork on demand; the manifest is generated by scripts/art.py |

## Build and test

```
node scripts/build.cjs            # writes ../index.html (and syncs paint/ into tpl.js)
node --test tests/*.test.cjs      # 12 tests
node scripts/build.cjs --check    # confirms index.html and tpl.js are current
python3 scripts/art.py            # only after adding or changing artwork in assets/
```

Test in a browser through a local server (`node scripts/serve.cjs`), not by opening the file directly, so artwork loads and exports work.

## Rules

- No real Japanese, Chinese or Korean characters; signage uses the invented script (fauxGlyph / fauxText in render.js).
- No ellipsis truncation in widgets or games: text shrinks, then wraps.
- Home screens stay clear of the icon row and the dock.
- Artwork is never embedded in index.html; add it under assets/<theme>/ and run scripts/art.py.
